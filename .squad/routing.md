# Work Routing

How to decide who handles what.

## Routing Table

| Work Type | Route To | Examples |
|-----------|----------|----------|
| Architecture, scope, decisions | Mikey | App structure, API contracts, tech stack choice |
| Web UI, components, visualization | Andy | Comparison views, side-by-side output, charts |
