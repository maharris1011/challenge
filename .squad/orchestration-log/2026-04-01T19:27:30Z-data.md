## Work Completed

### 1. Replaced String-Based Digit Extraction
- Implemented arithmetic loop: `n % 10` / `n /= 10` 
- **Impact:** Eliminated ~387M heap allocations (p=9)
- **Result:** Zero-allocation digit extraction

### 2. Pre-Computed Power Cache
- Added `[u64; 10]` cache initialized with `std::array::from_fn`
- Powers (0–9)^p computed once per run
- **Impact:** Removed repeated pow() calls in inner loop

### 3. Rayon Parallel Iteration
- Applied adaptive parallelism: p >= 7 uses `into_par_iter()`
- p < 7 remains sequential (thread pool overhead not justified)
- Added `sort_unstable()` after parallel collect to preserve order
- **Impact:** p=7 achieves 0.04s wall time (~9x user-to-wall-time ratio)

### 4. Dependency Cleanup
- Removed `num-traits` (only used for `pow()`, now using native `u64::pow()`)
- Added `rayon = "1"` dependency

### 5. Output Format Preserved
- Maintained `println!("{:?}", results)` — webapp parser compatible
