# What the Team is Focused On

**Last updated:** 2026-04-01

## Current Focus

Building a web app to compare the `3-sum-of-digits-to-power` (narcissistic number finder) algorithm implementations across 13 languages: Python, Java, Ruby, C, C++, C#, F#, Go, Haskell, Elixir, Node.js, Rust, Swift.

## In Scope

- Challenge 3 only (`3-sum-of-digits-to-power/`)
- Web UI for running and comparing language implementations side by side
- Execution engine (backend) to run each language's code and capture output
- Output comparison/visualization

## Out of Scope

- Challenge 1 (`1-count-characters/`) — explicitly excluded
- Challenge 2 (`2-reverse-linked-lists/`) — explicitly excluded
